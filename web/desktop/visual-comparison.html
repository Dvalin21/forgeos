Recommendation: Inline SVG Icon System

  • No external dependency - inline SVG keeps it zero-dependency like the rest of ForgeOS
  • Customizable via CSS - stroke, fill, width, height all controllable
  • Consistent sizing - all icons 24x24 viewBox
  • Accessible - add title/aria-label as needed
  • Creative freedom - design brand-specific icons for ForgeOS

5. Research Summary - Modern NAS UI Trends (2025-2026)

🥛 Glassmorphism

MarkOS, luci-theme-glass
backdrop-filter: blur(), translucent panels, inset highlights. Premium feel.

✨ Aurora/Deep Space

NOWEN (星云门户)
Animated gradients, star fields, "深空" aesthetic. Immersive.

🎨 Customizable

FlatNAS, OpenWrt
User-selectable wallpapers, drag-drop layouts, theme switching.

📊 Dashboard-Centric

NAS-Panel, BaluHost
Widget-based layouts, real-time monitoring, Docker integration.

💻 Terminal Integration

MarkOS, RedNeck-NAS
Web-based terminals (xterm.js), SSH access, container exec.

🎭 Icon Systems

Lucide, Heroicons
SVG icon libraries, consistent sizing, CSS customizable.
