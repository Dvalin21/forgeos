Daemon settings

How aggressively ForgeDB snapshots and how many it keeps.

Compatibility. ForgeDB watches and protects file-based databases used over SMB. It coordinates locks (preventing the corruption that single-file databases suffer when multiple clients write at once), and it snapshots on writes so you can recover instantly if something goes sideways.
SQLite (.db, .sqlite) ElevateDB (.edb) Atrex / DBISAM (.dat, .idx) Microsoft Access (.mdb, .accdb) dBase / FoxPro (.dbf) NexusDB Paradox (.db, .px)

Only SQLite and dBase files can be created directly from the NAS — every other format needs the app to create its own files on first run. Use Prepare directory for app for those.
